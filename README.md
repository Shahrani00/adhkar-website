# حصن المسلم | موقع أذكار الصباح والمساء 🕌

موقع عربي (RTL) يعرض أذكار الصباح والمساء بأحاديث صحيحة مع ذكر المصدر لكل حديث.

## المزايا
- ✅ جميع الأحاديث صحيحة السند (البخاري، مسلم، السنن بتصحيح الألباني) مع المصدر ورقم الحديث
- 🌅🌙 أذكار الصباح (18) والمساء (18) مع عداد وتقدم محفوظ
- 🌓 وضع نهاري / مسائي / تلقائي
- ✍️ الخط السعودي (Tajawal / Almarai) مع تخصيص اللون وحجم الخط
- 📿 مسبحة إلكترونية للأنواع الأربعة بعد الصلوات (سبحان الله، الحمد لله، الله أكبر، التهليل) بطريقتين صحيحتين
- 📱 تصميم عصري متجاوب — ملف واحد `index.html` بدون أي اعتماديات

## النشر على GitHub Pages
الموقع ملف واحد، يُنشر مباشرة:
`Settings → Pages → Deploy from a branch → main / (root)`

## التشغيل محلياً
افتح `index.html` في المتصفح مباشرة، أو:
```bash
npx serve .
```

تقبّل الله منا ومنكم 🤲
